3. API Endpoints

POST /api/score — Record play result
Body: { game, userId, name, email?, score, level, mode, extra? }
Response: { ok: true }
GET /api/leaderboard?game=xxx&period=all|week — Top 20 players
Response: { rows: [...], period }
Cache: 30s
POST /api/user — Upsert user profile
Body: { userId, name, email? }
POST /api/heartbeat — Online presence ping (30s interval)
Body: { userId, game? }
POST /api/track — Visitor + pageview tracking
Body: { type: 'session'|'pageview', sid, game? }
Response: { ok: true, newSession?: boolean }
GET /api/stats?all=1 — Aggregated stats (players, online, plays, visitors, views)
Response: { totalVisitors, totalPageviews, games: [...] }
GET /healthz — Health check
Response: { ok: true, ts }

5. Authentication

  • Guest mode: Auto-generate guest_uuid in localStorage
  • Google OAuth2: Google Identity Services SDK, token verified via oauth2.googleapis.com/tokeninfo
  • Token flow: POST /api/score with Bearer token — server validates Google ID token matches userId
  • Rejection: Claims google_ prefix without token = 401

6. Platform Features

Hub (index.html)

  • Game card grid — Featured (2) + All Games (8)
  • Daily Challenge — deterministic hash(today) picks game
  • Streak counter — localStorage, resets if gap > 1 day
  • Site-wide stats bar — visitors, views (from /api/stats)
  • i18n — EN/VI/JA, auto-detect from navigator.language
  • Theme toggle — dark/light, stored in localStorage

Game Shell (game-platform.js)

  • Phone-style status bar (clock, signal, battery)
  • Top/bottom ad slots (30px each)
  • Overlay system: pause, settings, how-to-play, profile
  • IndexedDB storage: history, top scores, profile
  • Google login modal
  • Heartbeat ping (30s interval)
  • Interstitial ad support (disabled in MVP)

CSP (Content Security Policy)

  • script-src: self, unsafe-inline, accounts.google.com, gstatic.com, cloudflareinsights.com, challenges.cloudflare.com
  • frame-src: accounts.google.com, challenges.cloudflare.com
  • connect-src: self, https:
