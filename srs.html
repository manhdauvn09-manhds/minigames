Xác Thực — Google Authentication

Flow đăng nhập

User click "Đăng nhập với Google" │ ▼ Supabase Auth → Google OAuth 2.0 redirect │ ▼ Google consent screen │ ▼ Callback → Supabase Auth xử lý token │ ├── User mới → tạo bản ghi users + user_profiles tự động └── User cũ → update last_active_at, trả về session │ ▼ Redirect về app (Language selection screen)

Triển khai kỹ thuật

Supabase Auth tích hợp sẵn Google OAuth — chỉ cần cấu hình Google Cloud Console OAuth Client ID và Client Secret trong Supabase dashboard. Không cần code auth server riêng.

// lib/auth.ts — Supabase Google OAuth
export async function signInWithGoogle() {
  const { error } = await supabase.auth.signInWithOAuth({
    provider: 'google',
    options: {
      redirectTo: `${location.origin}/auth/callback`,
      queryParams: { access_type: 'offline', prompt: 'select_account' }
    }
  });
  if (error) throw error;
}

// app/auth/callback/route.ts — Next.js route handler
export async function GET(request: Request) {
  const { searchParams } = new URL(request.url);
  const code = searchParams.get('code');
  if (code) await supabase.auth.exchangeCodeForSession(code);
  return NextResponse.redirect('/languages');
}

Karaoke Text Highlight & TTS

Good morning everyone, how are you today?
I am fine, thank you very much!
0.75x1.0x1.25x1.5x2.0x 🔄 Tăng dần: bật 📖 Select từ → từ điển

Cơ chế đồng bộ

Web Speech API SpeechSynthesisUtterance.onboundary trả về charIndex + charLength → highlight đúng từ/câu. Không dùng file audio → không tốn storage.

const utterance = new SpeechSynthesisUtterance(text);
utterance.rate  = playbackRate;  // 0.5 – 2.0
utterance.voice = selectedVoice;
utterance.onboundary = ({ charIndex, charLength }) => {
  highlightRange(charIndex, charLength);  // đổi màu từ
};
utterance.onend = () => handleRepeatMode();
speechSynthesis.speak(utterance);

Từ Tiếng Việt có gốc Hán

Khi người dùng đang học tiếng Việt và select một từ có gốc Hán Việt (ví dụ: "học sinh", "giáo viên", "quốc gia"), popup hiển thị: chữ Hán gốc, cách đọc tiếng Nhật (phiên âm), nghĩa tiếng Nhật, ví dụ cách dùng trong tiếng Nhật.

Ví dụ: "học sinh" → 学生 (がくせい, gakusei) → 学生 trong tiếng Nhật cũng có nghĩa tương đương → giúp học viên liên kết kiến thức JA-VI.

Free APIs sử dụng

🇯🇵 Jisho.org API FREE
https://jisho.org/api/v1/search/words?keyword={word}
Từ điển Nhật đầy đủ nhất. Trả về: readings (kana + romaji), meanings (EN), JLPT level, parts of speech, sentences. Unofficial API nhưng ổn định lâu năm. Không cần API key.
🇺🇸 Free Dictionary API FREE
https://api.dictionaryapi.dev/api/v2/entries/en/{word}
Từ điển Anh mã nguồn mở. Trả về: phonetics (IPA), audio pronunciation URL, definitions, examples, synonyms. Không cần API key. Rate limit thoải mái.
🔄 MyMemory Translation FREE
https://api.mymemory.translated.net/get?q={text}&langpair={from}|{to}
Dịch đa ngôn ngữ. 5,000 words/ngày không cần key. 10,000 words/ngày với email đăng ký miễn phí. Hỗ trợ JA↔VI, EN↔VI, JA↔EN. Dùng cho đoạn dài.
🇻🇳 Sino-Vietnamese Mapping FREE
Client-side JSON lookup (kanji → hán việt)
File JSON nhỏ (~200KB) map từng kanji sang âm Hán Việt dựa trên Unihan database. Load một lần và cache trong browser. Không cần server call. Ví dụ: 会→hội, 議→nghị.
💡 Fallback chain cho dịch thuật:
1. MyMemory (primary — free, không cần key)
2. LibreTranslate public instance (backup nếu MyMemory rate limit)
3. Google Translate unofficial qua thư viện @vitalets/google-translate-api (backup cuối — unstable nhưng không giới hạn rõ ràng)

Caching: Kết quả tra từ điển cache trong sessionStorage (mỗi session) và user_favorites nếu user lưu — tránh gọi API trùng lặp.

Logic chọn API theo ngữ cảnh

async function lookupSelection(text: string, lang: string) {
  const wordCount = text.split(/\s+/).length;
  const charCount = text.length;

  if (charCount <= 20 && wordCount <= 2) {
    // 1 từ → gọi từ điển chi tiết
    if (lang === 'ja') return jishoLookup(text);         // JA dict
    if (lang === 'en') return freeDictLookup(text);      // EN dict
    if (lang === 'vi') return viWordLookup(text);       // Sino-VI map
  }

  // Cụm từ / đoạn dài → dịch nghĩa
  const targetLang = lang === 'ja' ? 'vi' : lang === 'vi' ? 'en' : 'vi';
  return translateText(text, lang, targetLang);  // MyMemory API
}

Favorite Words TÍNH NĂNG MỚI

Thiết kế nguyên tắc

Chỉ lưu keyword (từ khóa), không lưu data từ điển. Khi xem lại, tra lại API từ điển realtime. Lý do: (1) Data từ điển có thể thay đổi, cần luôn fresh; (2) Giảm storage Supabase (mỗi bản ghi chỉ ~100 bytes thay vì ~2KB); (3) API miễn phí nên không tốn cost khi tra lại.

UX flow lưu từ

1. Trên màn hình luyện tập, user select từ → Dictionary popup xuất hiện

2. Click "⭐ Lưu từ này" → toast "Đã lưu vào Favorite"

3. Chỉ lưu: keyword, language_code, lesson_id (context), created_at

4. Trên màn hình Favorites → click từ → gọi lại API từ điển → hiện popup giống hệt lúc tra lần đầu

DB Schema — bảng mới

-- Chỉ lưu keyword, không lưu dictionary data
CREATE TABLE user_favorites (
  id           uuid PRIMARY KEY DEFAULT gen_random_uuid(),
  user_id      uuid REFERENCES users(id) ON DELETE CASCADE,
  keyword      varchar(200) NOT NULL,
  language_code varchar(5) NOT NULL,  -- 'ja', 'en', 'vi'
  lesson_id    uuid REFERENCES lessons(id) ON DELETE SET NULL,
  notes        text,                   -- ghi chú cá nhân (optional)
  created_at   timestamptz DEFAULT NOW(),
  UNIQUE(user_id, keyword, language_code)  -- không lưu trùng
);

API Design

Authentication
POST/api/auth/registerĐăng ký email + password
POST/api/auth/loginĐăng nhập, trả session cookie
GET/api/auth/google/callbackOAuth callback Google → tạo/merge user
GET/api/auth/meThông tin user hiện tại
Content
GET/api/languagesDanh sách ngôn ngữ
GET/api/languages/:lang/categoriesDanh mục + tiến độ user + count bài mới hôm nay
GET/api/categories/:id/lessons?new=trueBài học, flag "new=true" để lọc bài mới nhất
GET/api/lessons/:idChi tiết bài + transcript + furigana_json
Dictionary & Translation (proxy để tránh CORS)
GET/api/dict/ja/:wordProxy → Jisho API, trả về readings, meanings, JLPT, examples + tính âm Hán Việt
GET/api/dict/en/:wordProxy → Free Dictionary API, phonetics, definitions, examples
POST/api/dict/translateBody: {text, from, to} → MyMemory → dịch đoạn văn
GET/api/dict/vi/:wordTìm gốc Hán của từ Tiếng Việt, tra JA equivalent
Favorite Words — MỚI
GET/api/favoritesDanh sách từ yêu thích của user, filter ?lang=ja
POST/api/favoritesLưu từ: {keyword, language_code, lesson_id}
DELETE/api/favorites/:idXóa từ khỏi favorite
Progress
POST/api/progress/sessionsTạo phiên học
PUT/api/progress/sessions/:idKết thúc phiên + lưu kết quả
GET/api/progress/summaryXP, streak, tổng phút, favorites count
Admin — Crawl
GET/api/admin/crawl/sourcesDanh sách nguồn crawl
POST/api/admin/crawl/sourcesThêm nguồn mới
POST/api/admin/crawl/sources/:id/triggerTrigger thủ công
GET/api/admin/crawl/raw-items?status=pendingReview nội dung chờ duyệt
POST/api/admin/crawl/raw-items/:id/approveApprove → tạo lesson
Dictionary API proxy — các endpoint /api/dict/* là Next.js API Routes proxy đến các free APIs bên ngoài. Lý do cần proxy: (1) tránh CORS khi gọi từ browser, (2) có thể add caching layer (cache response 24h trong Supabase hoặc Vercel Edge Cache), (3) dễ đổi provider sau này.

GitHub Actions — 3 workflows

# .github/workflows/crawl-it-daily.yml
on:
  schedule:
    - cron: '0 6 * * *'   # Hàng ngày 6:00 AM UTC (13:00 JST)
  workflow_dispatch:       # Admin trigger thủ công
jobs:
  crawl:
    runs-on: ubuntu-latest
    timeout-minutes: 20
    strategy:
      matrix:
        source: [nhk-easy, gigazine-tech, itmedia, zenn, qiita, hatena-tech]
    steps:
      - name: Crawl ${{ matrix.source }}
        run: node scripts/crawl.js --source=${{ matrix.source }}
        env:
          SUPABASE_URL: ${{ secrets.SUPABASE_URL }}
          SUPABASE_SERVICE_KEY: ${{ secrets.SUPABASE_SERVICE_KEY }}
