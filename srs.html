Giới Thiệu

Tầm nhìn sản phẩm

ShadowLing là nền tảng web luyện nghe-nói theo phương pháp shadowing — người học nghe và nhại theo âm thanh gần như đồng thời. Giao diện hiển thị text đổi màu theo từng từ/câu đang được đọc (kiểu karaoke đơn giản), giúp người học theo dõi và bắt chước chính xác.

Toàn bộ hệ thống sử dụng các dịch vụ miễn phí hoàn toàn — không phát sinh chi phí hạ tầng.

Phạm vi hệ thống

Trong phạm vi (In Scope)

✅ Web app đa ngôn ngữ (EN, VI, JA)  |  ✅ TTS browser built-in (Web Speech API)  |  ✅ Text highlight karaoke  |  ✅ Tốc độ 0.5x–2.0x  |  ✅ Repeat modes  |  ✅ Progress tracking  |  ✅ Admin panel  |  ✅ Data crawling tự động

Ngoài phạm vi (Out of Scope — Phase 1)

❌ Mobile app native  |  ❌ Ghi âm & chấm điểm phát âm  |  ❌ Thanh toán / Premium  |  ❌ Video content  |  ❌ Real-time multiplayer

Karaoke Text Highlight & TTS

Cách hoạt động

Không dùng file audio lưu trữ. Toàn bộ TTS chạy trong browser bằng Web Speech API — miễn phí, không cần server. Sự kiện onboundary của SpeechSynthesisUtterance cung cấp vị trí ký tự đang đọc (charIndex, charLength) → highlight đúng từ/câu trên màn hình.

Good morning everyone, how are you today?
I am fine, thank you very much!
0.75x 1.0x 1.25x 1.5x 2.0x 🔄 Tăng dần tốc độ: bật

Demo giao diện karaoke — từ "morning" đang được highlight (màu vàng)

Hai chế độ highlight

Chế độMô tảPhù hợp
Word level Từng từ đổi màu theo tiến trình, từ đã qua mờ đi, từ active in đậm + màu nổi Tiếng Anh, Tiếng Nhật
Sentence level Cả câu đang đọc đổi màu nền, các câu khác mờ hơn Tiếng Việt, bài dài

Code cốt lõi — Web Speech API

const utterance = new SpeechSynthesisUtterance(text);
utterance.rate  = 0.75;   // tốc độ 0.5–2.0
utterance.voice = selectedVoice;  // giọng nam/nữ đã chọn
utterance.lang  = "en-US";

// Sự kiện quan trọng: biết chính xác từ nào đang đọc
utterance.onboundary = (event) => {
  const { charIndex, charLength } = event;
  highlightText(charIndex, charLength); // đổi màu đoạn text
};

utterance.onend = () => {
  if (repeatMode === "progressive") {
    currentSpeed = nextSpeed(currentSpeed); // tăng tốc độ
    if (!currentSpeed) showCompletionScreen();
    else startSpeaking();
  } else {
    startSpeaking(); // loop cùng tốc độ
  }
};

speechSynthesis.speak(utterance);

API được implement dưới dạng Next.js API Routes (/app/api/...), không cần server riêng. Tất cả đều gọi Supabase client phía server với Row Level Security (RLS).

POST/api/auth/loginĐăng nhập, trả về session cookie
POST/api/auth/logoutXóa session
GET/api/auth/meThông tin user hiện tại
GET/api/auth/google/callbackOAuth callback từ Google

GET/api/languagesDanh sách ngôn ngữ

GET/api/categories/:id/lessonsBài học trong danh mục
GET/api/lessons/:idChi tiết bài học + transcript

Hệ Thống Crawl Dữ Liệu

GitHub Actions — Crawler miễn phí

# .github/workflows/crawl.yml
on:
  schedule:
    - cron: '0 2 * * 1'    # Mỗi thứ Hai 2:00 AM UTC
  workflow_dispatch:        # Admin trigger thủ công từ GitHub UI

jobs:
  crawl:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4
      - run: npm ci
      - run: node scripts/crawl.js
        env:
          SUPABASE_URL: ${{ secrets.SUPABASE_URL }}
          SUPABASE_KEY: ${{ secrets.SUPABASE_KEY }}

Workflow crawl → bài học

#BướcCông nghệ
1GitHub Actions kích hoạt script crawlGitHub Actions cron
2Fetch HTML theo URL pattern + CSS selectors trong crawl_sourcesCheerio / Playwright

5Admin review trên giao diện → approveAdmin UI

Không có TTS server — audio được generate realtime bằng Web Speech API khi người dùng bắt đầu luyện tập.
