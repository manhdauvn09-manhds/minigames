Request → Response Flow

User clicks "Play Game" ↓ game-platform.js loads individual game (games/gameId/) ↓ Canvas/game rendering begins (or WebGL) ↓ User plays levels 1–30, completes level N ↓ Game calls: GamePlatform.recordResult({ game: 'ballmerge', userId: 'guest_abc123' or 'google_xyz', score: 15000, level: 5, mode: 'normal' }) ↓ POST /api/score (with body) ↓ Express processes: validates game ID, inserts into scores_ballmerge, upserts users table ↓ Response: { ok: true } or { error: 'db_error' } ↓ game-platform.js updates local leaderboard if offline mode or caches result ↓ Next level auto-loads OR user returns to hub

🔌 6. API Endpoints

1. POST /api/score — Record play result

POST /api/score

Body:

{ "game": "ballmerge", // ✓ required, must be in whitelist "userId": "guest_abc123", // ✓ required "name": "Player Name", // ✓ required (max 30 chars) "email": "player@example.com", // optional "score": 15000, // ✓ required, clamped [0, 9999999] "level": 5, // ✓ required, clamped [0, 99] "mode": "normal", // ✓ required, "normal" or "adventure" "extra": "bonus_item_collected" // optional, game-specific metadata (max 200 chars) }

Response (200): { "ok": true }

Error (400/401/500): { "error": "invalid_game"|"invalid_user"|"invalid_token"|"db_error" }

Security: Google token verification (optional) — if token sent, must match userId prefix.

2. GET /api/leaderboard — Fetch top 20 players

GET /api/leaderboard?game=ballmerge&period=all

Query params:

  • game=ballmerge ✓ required, must be in whitelist
  • period=all|week optional, default "all"

Response (200):

{ "period": "all", "rows": [ { "user_id": "google_12345", "name": "Top Player", "best_score": 999999, "best_level": 30, "last_play": "2026-05-17T10:30:00Z" }, ... ] }

Cache:** 30s (public, both client & server)

3. GET /api/user — Fetch user profile

GET /api/user?id=guest_abc123

Response (200):

{ "user_id": "guest_abc123", "name": "Player Name", "email": "player@example.com", "type": "guest", "created_at": "2026-05-10T08:00:00Z", "last_seen": "2026-05-17T10:30:00Z" }

4. GET /api/stats — Real-time aggregated stats

GET /api/stats?all=1

Response (200):

{ "totalVisitors": 12500, "totalPageviews": 45000, "games": [ { "game": "ballmerge", "players": 2300, "online": 45, "plays": 8200, "visitors": 3100, "views": 12500 }, ... ] }

Note: Calculated from MySQL aggregates. Refreshed on index.html load.

5. POST /api/track — Visitor tracking

POST /api/track

Body:

{ "type": "session" | "pageview", // session = new visitor, pageview = click "sid": "uuid-from-sessionStorage" // unique session ID }

6. POST /api/heartbeat — Online presence ping

POST /api/heartbeat

Body:

{ "userId": "guest_abc123", "game": "ballmerge" // optional, current game }

Function: Updates sessions table, marks user online for 30s.

7. GET /healthz — Health check

GET /healthz

Response: { "ok": true, "ts": 1234567890 }
Use case: Docker health probe, load balancer check.

💾 7. Database Schema

Tables structure

-- Users (cross-game profile) CREATE TABLE users ( user_id VARCHAR(64) PRIMARY KEY, -- guest_xxx or google_sub name VARCHAR(30), email VARCHAR(120), type ENUM('guest', 'google'), created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP, last_seen TIMESTAMP ON UPDATE CURRENT_TIMESTAMP ) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4; -- Game-specific scores (one table per game) CREATE TABLE scores_ballmerge ( id INT AUTO_INCREMENT PRIMARY KEY, user_id VARCHAR(64) NOT NULL, name VARCHAR(30), email VARCHAR(120), score INT DEFAULT 0, -- clamped [0, 9999999] level INT DEFAULT 0, -- [0, 99] mode ENUM('normal', 'adventure'), extra VARCHAR(200), -- game-specific metadata played_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP, INDEX idx_user_game (user_id, played_at), INDEX idx_score (score DESC) ) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4; -- (similar for: chromamatch, stacktower, memoryflip, snakerush, -- bubbleblast, arkanoidx, numberslide) -- Session tracking (for online count) CREATE TABLE sessions ( session_id VARCHAR(64) PRIMARY KEY, user_id VARCHAR(64), game VARCHAR(32), created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP, expires_at TIMESTAMP, INDEX idx_expires (expires_at) ) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4;

SQL Injection Prevention

Whitelist approach (in _db.js): 
const GAMES = new Set(['ballmerge', 'chromamatch', ...]);
function tableFor(gameId) {
  if (!GAMES.has(gameId)) throw new Error('Invalid game');
  return '`scores_' + gameId.replace(/[^a-z0-9_]/g, '') + '`';
}

Connection pooling (MySQL2)

  • Pool size: 5 connections (suitable for single-instance)
  • Keep-alive: 10s initial delay
  • Prepared statements: ✅ All queries use ? placeholders
  • SSL: Optional (controlled via MYSQL_SSL env var)

New User Journey

Browser auto-detects language (or shows selector) ↓ 3. index.html loads: • Game Hub with 11 game cards • Daily Challenge section • Streak counter (initially 0) • Site-wide stats fetched from /api/stats ↓ 4. 📤 Send Score to Server

async function submitScore(score, level) { try { const res = await fetch('/api/score', { method: 'POST', headers: { 'Content-Type': 'application/json' }, body: JSON.stringify({ game: 'ballmerge', userId: getUserId(), // from GamePlatform name: getName(), // from local storage score: score, level: level, mode: 'normal', extra: null }) }); if (res.ok) { console.log('Score saved!'); // Proceed to next level or show leaderboard } else { console.error('Score save failed'); // Fall back to local storage } } catch (e) { console.error('Network error:', e); // Offline mode — queue for later } }
