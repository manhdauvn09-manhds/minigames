## 🎮 FUNCTIONAL REQUIREMENTS

### Gameplay
- Board: **15x15** default, configurable to 19x19
- Win: 5 consecutive stones (horizontal/vertical/diagonal)
- Human (X) vs Bot (O) — player can choose first/second
- Highlight winning line on game end
- Controls: New Game, Undo (undo 1 full turn = player+bot), Reset, Change Level

### 5 AI Difficulty Levels (must be measurably different)

| Level | Algorithm | Notes |
|-------|-----------|-------|
| **1 — Beginner** | Random moves; only blocks exact 4-in-a-row open threats | Beatable by total beginners |
| **2 — Easy** | Rule-based heuristic: block open-3/4, extend own line, center opening | No lookahead |
| **3 — Medium** | Minimax + alpha-beta pruning, depth 2–3; pattern scoring (open2/3/4, closed2/3/4, five); radius-2 move limit | |
| **4 — Hard** | Minimax + alpha-beta, depth 4; detect double-threats/forks; better move ordering | Response <2s |
| **5 — Expert** | Minimax + alpha-beta, depth 6 (or iterative deepening w/ ~3s budget); Zobrist transposition table; threat-space search (VCF) | Near-unbeatable for non-experts |

**CRITICAL:**
- All AI runs **client-side in JavaScript**
- Use **Web Workers** for level 4–5 to prevent UI freeze
- Provide a **self-test**: script where level 5 plays level 1 for 10 games — level 5 must win ≥9/10

### UX & Features
- Responsive: desktop + mobile
- Dark/Light theme toggle (tokens from Kaya Design System)
- Sound FX: place stone, win, lose + mute toggle
- Score tracking (W/L/D) per level, persisted in localStorage
- Move history panel (clickable to review positions)
- Bot thinking indicator (spinner/dots for level 4–5)
- Settings panel: level, board size, who-first, sound, theme
- Hint button (levels 1–2 only): suggest good move for human
- Timer (elapsed display, not hard limit)
- Resume game on page refresh (localStorage state)
