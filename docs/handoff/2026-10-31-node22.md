# Handoff — minigames Node 20 → 22 (2026-10-31)

## Mục tiêu
`minigames` (mcp-80) đang chạy Node **20.20.2** (EOL 04/2026). Nâng base image lên Node 22 LTS, giữ nguyên non-root user `app`.

## Thay đổi code
| File | Trước | Sau |
|---|---|---|
| `Dockerfile` | `FROM node:20-alpine AS runtime` | `FROM node:22-alpine AS runtime` (comment "Node 20 alpine" → "Node 22 alpine"; `USER app` giữ nguyên) |
| `docker-compose.yml` | `image: minigames:2.1.0` | `image: minigames:2.1.1` |
| `package.json` | `"version": "2.1.0"` | `"version": "2.1.1"` (`engines.node` giữ `>=20.0.0` — Node 22 vẫn thoả) |

Port/container không đổi: host `127.0.0.1:9210` → container `3333`, container name `minigames`.

## Rollback
Image cũ `minigames:2.1.0` vẫn còn trong local store trên mcp-80 (4 tháng tuổi). Nếu cần quay lại:
- Revert `Dockerfile` (`node:20-alpine`) + `docker-compose.yml` (`image: minigames:2.1.0`) rồi MCP `deploy` lại, HOẶC
- `cd /opt/minigames && docker compose up -d` với image pin `2.1.0` (skip build).
