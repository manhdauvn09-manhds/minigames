🔐 Administration Guide

⚠️ IMPORTANT: MiniGames is a public-facing gaming platform with NO DEDICATED ADMIN PANEL. There are no admin user accounts for game management. The platform is fully automated and self-service.

1. Platform Architecture

MiniGames follows a public, self-service model:

  • No admin user accounts or login system
  • No backend admin panel for game management
  • No moderation tools (all data auto-generated by users)
  • No game upload/configuration interface
  • All games deployed via code updates (Git + Docker)

⚙️ API Reference

All API endpoints are located at: https://minigames.allin1site.com/api/*

Method: REST + JSON
CORS: Enabled for minigames.allin1site.com

1. POST /api/score — Record Game Score

Purpose: Submit a game result and update user leaderboard position

Request Body:

{
  "game": "ballmerge",
  "userId": "google_103948134",
  "name": "John Doe",
  "email": "john@example.com",
  "score": 8500,
  "level": 15,
  "mode": "normal",
  "extra": "{\"combos\": 5, \"powerups\": 2}"
}

Response (Success):

{"ok": true}

Response (Error):

{"ok": false, "error": "Invalid game ID"}
